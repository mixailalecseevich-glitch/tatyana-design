# Сайт Татьяны К.

Адаптивное портфолио дизайнера карточек товаров, объявлений Avito и сообществ ВКонтакте.

Опубликованный сайт: https://mixailalecseevich-glitch.github.io/tatyana-design/

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Материалы Avito

В `public/assets/avito` находятся три серии по шесть изображений, 1080 × 1350 px. Тексты объявлений и аудит находятся в `docs/AVITO_LISTINGS.md` и `docs/AVITO_AUDIT.md`.

## Происхождение изображений

Реальные портреты Татьяны предоставлены пользователем. Предметные изображения созданы встроенным инструментом OpenAI Image Generation как демонстрационные исходники без логотипов и текста. Точные русские надписи и макеты собраны в HTML/CSS и экспортированы из `tools/creative-studio.html`.

Темы предметных генераций: сыворотка во флаконе, аккумуляторная дрель, набор контейнеров, лежанка для питомца, деревянные балансиры, настольная лампа и кроссовок. Все запросы требовали отсутствие брендов, логотипов, водяных знаков и читаемого текста.
