# Выполненный план

## Исследование

- изучен старый сайт и его техническое состояние;
- проверены фотографии Татьяны;
- проверены публичные контакты и выдача Avito;
- неподтверждённые утверждения исключены.

- собрано три направления объявлений;
- экспортировано 18 изображений 1080 × 1350 px;
- сохранён манифест происхождения материалов.

## Сайт
