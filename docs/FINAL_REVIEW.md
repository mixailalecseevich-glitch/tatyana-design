# Финальная проверка

Дата: 21 сентября 2026 года.

## Что готово

- Адаптивный сайт-портфолио для компьютеров и телефонов.
- Три направления: инфографика для маркетплейсов, оформление объявлений и карточек Avito, оформление сообществ ВКонтакте.
- 18 готовых изображений для объявлений: три серии по шесть файлов, размер каждого 1080 × 1350 px.
- Три готовых текста объявлений и рекомендуемый порядок изображений.
- Аудит публичной выдачи Avito с выводами по позиционированию, заголовкам, визуалам и ценам.
- Автоматическая публикация сайта через GitHub Pages после каждого обновления ветки `main`.

## Проверки сайта

- Production-сборка: успешно.
- TypeScript: ошибок нет.
- Desktop 1440 × 1000: переполнения по горизонтали нет, изображения загружаются.
- Mobile 390 × 844: переполнения по горизонтали нет, нижние кнопки и меню работают.
- Битые изображения: 0.
- Изображения без альтернативного текста: 0.
- Дублирующиеся идентификаторы: 0.
- Lighthouse: Performance 90, Accessibility 100, Best Practices 100, SEO 100.
- FCP 0,9 с; LCP 3,7 с; CLS 0; TBT 0 мс в локальной проверке.

## Проверки материалов Avito

- `marketplace-01.png` ... `marketplace-06.png`: 6 файлов.
- `avito-01.png` ... `avito-06.png`: 6 файлов.
- `vk-01.png` ... `vk-06.png`: 6 файлов.
- Все серии используют разные визуальные системы и соответствуют своему направлению.
- Демонстрационные изображения на сайте прямо обозначены как концепты, реальные отзывы, цены и результаты не выдуманы.

## Ограничения исследования

Публичную выдачу Avito удалось проверить. Страница ВКонтакте ограничивала автоматический просмотр публикаций, поэтому работы из группы не выдаются за изученные или перенесённые. В проекте использованы фотографии, переданные пользователем, и новые демонстрационные концепты.
